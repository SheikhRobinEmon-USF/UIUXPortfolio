# Master plan — SRE Design & Interaction

Standalone UI/UX portfolio. Existing AI product-management portfolio is out of scope.

1. Reference study and concept registry.
2. Static-export Next.js foundation, cinematic seven-project browser, direct routes.
3. ATELIER, COMMON, FRAME, VITAL, MONETA, CRAVE and ROAM: synthetic datasets, independent visual themes, local persistence, primary workflows.
4. Case studies with research assumptions, personas, journey diagrams, wireframes, visual systems, decisions and live links.
5. Responsive and accessibility review, snapshot capture, functional tests, production build and release.

Architecture: `app/` contains routes, `components/` contains portfolio and prototype interactive UI, `lib/` contains the project registry and original artwork generator, `public/media/` contains local artwork and sample video, `tests/` contains browser and static verification. The seven concepts share mechanical state utilities but have distinct themes and domain-specific navigation. No backend or credentials required. See PROJECT_STATUS for remaining acceptance items.
